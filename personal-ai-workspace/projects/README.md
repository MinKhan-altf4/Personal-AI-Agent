# Projects

Create one folder per substantial project. Keep product source code in its own repository; this folder stores context, plans, decisions, and links.

Suggested starting projects:
- `mmorpg-knights-demons/`
- `fde-learning/`
- `winter-arc/`
- `university/`
- `business-lab/`

Start each folder with `templates/project-context.md`. Add only the documents the project needs, such as `ROADMAP.md`, `TASKS.md`, `DECISIONS.md`, `RISKS.md`, and `CHANGELOG.md`.

Do not assume the suggested project list is exhaustive or that every project is currently active.
